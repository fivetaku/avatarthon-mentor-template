# 아바타톤 로블록스편 멘토 과제 제출함

아바타톤 로블록스편(2026년 12월 5일 토, 성남 갤러리OA) 멘토 신청용 템플릿입니다.
AI에게 말로 시켜 로블록스 게임을 하나 만든 뒤, 그 과정을 이 레포에 정리해 공개로 올립니다.
만든 레포 주소를 신청서에 붙이면 제출이 끝납니다.

## 제출물

| 폴더·파일 | 내용 |
|---|---|
| `game/` | 게임 소스(Luau 코드, Rojo 설정 등) |
| `video/play.mp4` | 1~3분 플레이 영상. 말로 설명하며 찍어 주세요 |
| `sessions/` | AI와 나눈 대화 기록. 개인정보와 키는 지웁니다 |
| `PROCESS.md` | 막힌 곳과 푼 방법, 아이에게 알려 주고 싶은 것 |
| `SUBMISSION.json` | 닉네임, 쓴 코딩 AI, 한 줄 소개, 게임 주소 |

## 제출하는 법

1. 이 페이지 위의 **Use this template**으로 내 계정에 공개 레포를 만들고 내 컴퓨터에 받습니다.
   명령으로는 한 줄입니다.
   ```
   gh repo create avatarthon-mentor --template fivetaku/avatarthon-mentor-template --public --clone
   ```
2. 받은 폴더에서 Claude Code나 Codex를 열고 "아바타톤 제출해줘"라고 말합니다.
   게임 폴더, 영상 파일, 게임 주소, 닉네임을 물어본 뒤 나머지를 정리합니다.
3. 올리기 전에 정리된 대화 기록과 파일 목록을 보여 줍니다. 확인하고 "올려"라고 하면 올라갑니다.
4. 레포 주소를 신청서에 붙여 주세요.

웹 채팅에서 만든 경우에는 대화를 텍스트로 복사해 두었다가 제출할 때 넣으면 됩니다.

## 개인정보와 안전

- 대화 기록은 사람이 쓴 말과 AI의 답, AI가 쓴 도구 이름만 옮깁니다. 도구 실행 결과와 파일 내용은 옮기지 않습니다.
- 이메일, 전화번호, 주민번호, 카드번호, API 키, 로블록스 로그인 쿠키, 내 컴퓨터 사용자 이름이 든 경로는 자동으로 지웁니다.
  실명·회사명처럼 규칙으로 못 잡는 것은 올리기 전에 직접 확인해 주세요.
- 영상은 새 mp4로 다시 만들어 위치 정보 같은 메타데이터를 남기지 않습니다.
- 실행 파일, 압축 파일, 원본 영상은 받지 않습니다. 올리면 GitHub Actions의 "제출물 검사"가 확인합니다.
  직접 검사하려면 `python3 scripts/check_submission.py .`

## 필요한 것

Python 3, git, ffmpeg(영상 압축), 그리고 Claude Code나 Codex 중 하나. `gh`(GitHub CLI)가 있으면 편합니다.
