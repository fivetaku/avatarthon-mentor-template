## 머리

12월 5일(토) 성남 갤러리OA에서 아이와 가족이 로블록스 게임을 만듭니다.
옆에서 함께 만들어 줄 멘토를 찾습니다. 먼저 직접 게임을 하나 만들어 보는 것이 신청 과제입니다.

- 마감: **11월 23일**
- 사례비: 조당 15만 원
- 신청: avatarthon.axwith.com/mentor

## 신청 과제 — 4단계

**S1. 게임과 에셋 만들기**
로블록스 스튜디오에서 작은 게임을 하나 만들고, 게임에 놓을 소품(에셋)을 만듭니다.
기본은 스튜디오의 기본 파트를 조립하는 것이고, 선택으로 Blender 메시나 VARCO 3D를 써 봅니다.

**S2. 직접 플레이하기**
만든 게임을 직접 해 보고, 말로 설명하며 1~3분 플레이 영상을 찍습니다.
재미있던 점과 어색했던 점을 적어 두세요. 행사 당일 아이에게 해 줄 말이 됩니다.

**S3. 키트로 정리해 공개 레포 만들기**
멘토 키트 템플릿으로 내 GitHub에 공개 레포를 만들고, 결과물을 넣어 정리합니다.
키트가 게임 파일·에셋·영상·작업 기록을 나누고, 개인정보를 지우고, 검사까지 합니다.
게임 만드는 법은 키트가 알려 주지 않습니다. 직접 만든 결과물을 정리하는 도구입니다.

**S4. 구글 폼에 등록하기**
레포 주소와 함께 신청 폼(14문항)을 작성합니다. 어떤 도구(VARCO·Blender·기타)로 만들었는지도 묻습니다.

## 제출물

| 항목 | 내용 |
|---|---|
| 게임 파일 | `game/` — 스튜디오에서 저장한 `.rbxlx` 등 |
| 에셋 | `assets/` — 이미지, FBX·OBJ·GLB, `.rbxmx` |
| 플레이 영상 | 1~3분 |
| 작업 기록 | 메모·스크린샷, AI 대화 기록(썼다면) |
| 과정 정리 | 무엇을 어떤 도구로 만들었나, 플레이 소감, 막힌 곳, 아이에게 알려 줄 것 |

게임 파일과 에셋은 둘 다 있어야 합니다.

## 자주 묻는 것

- **로블록스 스튜디오를 처음 써도 되나요?** 됩니다. 과제를 해 보며 익히는 것이 목적입니다.
- **VARCO나 Blender를 꼭 써야 하나요?** 아니요. 기본 파트만으로도 됩니다. 쓴 도구를 폼에 적어 주세요.
- **코딩 AI가 필요한가요?** 아니요. 키트는 Python만 있으면 돌아갑니다.
- **개인정보 동의는요?** 동의 세부 내용은 신청 폼에서 안내하고 받습니다.
